# 03 建立第二大脑

## 目标

把 `lazy-package` 仓库变成 Obsidian 可以打开、Codex 可以协助整理、GitHub 可以同步保存的第二大脑。

## 连接方式

1. 打开 Obsidian
2. 选择“打开本地资料库”
3. 选择这个文件夹：

```text
C:\Users\蔡雯婷\Documents\懒人包
```

4. 打开后，从 [[../00-开始这里/00-首页]] 开始

## 资料夹分工

| 资料夹 | 用途 |
|---|---|
| `00-开始这里` | 首页、总目录、导航 |
| `01-Codex基础` | Codex 安装、设置、工具检查 |
| `02-GitHub连接` | GitHub 连接、仓库发布 |
| `03-Obsidian第二大脑` | Obsidian 笔记系统 |
| `08-ImageGen` | 图片生成与素材制作 |
| `收件箱` | 临时想法、未整理资料 |
| `模板` | 笔记模板 |
| `素材库` | 图片、附件、课程素材 |

## 工作流

1. 临时资料先进 [[../收件箱/收件箱]]
2. 整理后移动到对应课程笔记
3. 每一集有一份主题笔记
4. 完成后用 GitHub 同步
